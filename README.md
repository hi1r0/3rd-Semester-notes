# MSQF Semester III Notes

Comprehensive course notes, lecture materials, presentations, and LaTeX study documents for M.Sc. Quantitative Finance (Semester III) at Pondicherry University.

---

## 📚 Repository Structure

```
.
├── Financial Mathematics/
│   ├── notes.docx
│   └── latex/                     # LaTeX sources, preamble, chapters & compiled notes
├── Global Financial Management/
│   ├── notes (GFM).docx           # GFM course notes
│   └── latex/                     # Modular LaTeX notes, TikZ flowcharts & compiled notes
├── ML/
│   ├── QF_sem_3_ML_U1P1.pdf       # Unit 1 Part 1 Slides
│   ├── QF_sem_3_ML_U2_PPT1.pdf    # Unit 2 Presentation
│   ├── QFS3U1 Note.pdf            # Unit 1 Notes
│   └── QFS3U1E1.pdf               # Unit 1 Exercises
└── Time Series/
    └── latex/                     # LaTeX source, flowcharts & compiled notes
```

---

## 📖 Subjects Covered

1. **Financial Mathematics**
   - Interest theory, annuities, bonds, and cash flow analysis.
   - LaTeX source code with custom environments, macros, and full syllabus notes.

2. **Global Financial Management (GFM)**
   - International financial markets, exchange rate mechanisms, and currency risk management.

3. **Machine Learning (ML)**
   - Machine learning algorithms and statistical learning applications in finance.

4. **Time Series Analysis**
   - Univariate time series modeling, smoothing, multivariate/cointegration, volatility modeling (ARCH/GARCH), and forecasting evaluation.

---

## 🛠️ Building LaTeX Notes

To compile the LaTeX notes in `Financial Mathematics/latex` or `Time Series/latex`:

```bash
pdflatex main.tex
# or using latexmk
latexmk -pdf main.tex
```
